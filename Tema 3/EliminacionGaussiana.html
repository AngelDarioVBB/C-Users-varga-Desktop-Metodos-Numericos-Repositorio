Método de Eliminación Gaussiana

Métodos Numéricos - Tema 3

Objetivo

Reducir un sistema de ecuaciones lineales a una forma triangular superior mediante operaciones elementales entre filas, permitiendo resolver las incógnitas de forma secuencial (sustitución hacia atrás).

Descripción

El proceso consiste en eliminar sistemáticamente las variables de las ecuaciones. Se trabaja con la matriz aumentada y se busca que todos los elementos debajo de la diagonal principal sean cero.

Pseudocódigo

1. Para cada columna k (pivote): 2. Para cada fila i debajo del pivote: 3. Factor = A[i,k] / A[k,k] 4. Fila[i] = Fila[i] - Factor * Fila[k] 5. Sustitución hacia atrás para hallar x[n]...x[1]

Código en Python

import numpy as np def eliminacion_gaussiana(A, b): n = len(b) Ab = np.concatenate((A, b.reshape(n, 1)), axis=1).astype(float) for i in range(n): for k in range(i + 1, n): factor = Ab[k][i] / Ab[i][i] Ab[k, i:] -= factor * Ab[i, i:] x = np.zeros(n) for i in range(n-1, -1, -1): x[i] = (Ab[i,-1] - np.dot(Ab[i,i+1:], x[i+1:])) / Ab[i,i] return x
